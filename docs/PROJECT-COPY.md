# Public project copy

Repository name: `discord-clean-csv-exporter`

GitHub description:

Local-only Chrome extension to export Discord conversations as CSV or JSON, with date ranges, message filters, previews, and partial-export recovery. No bot or account token required.

Website summary:

Discord Clean CSV Exporter is a lightweight Chrome extension for turning Discord conversations into CSV or JSON files. Choose a date range, filter by author or keyword, exclude media or bot messages, and preview the results before downloading. Processing stays in your browser, with pause/resume controls and clear partial-export reporting. No bot, account token, or external service is required.
